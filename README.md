# Library Frontend

A modern, responsive frontend for a library management system built with **React**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**. Supports viewing, borrowing, and managing books with toast notifications and dialog confirmations.

## Features

- Responsive design for mobile & desktop
- Fetch books from backend using **RTK Query**
- Borrow books and track summaries
- Loading page, toast notifications, and dialog confirmations
- Featured books section with cards
- Modern Navbar and Footer components
- Clean TypeScript structure

## Tech Stack

- **React 19+**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **Redux Toolkit + RTK Query**
- **React Router v6**
- **Vite** as bundler

## Installation

```bash
# Clone the repo
git clone https://github.com/your-username/library-frontend.git
cd library-frontend

# Install dependencies
npm install

# Start the development server
npm run dev
